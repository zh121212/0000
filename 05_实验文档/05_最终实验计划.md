## 1. 工程准备（P13）

**目录。** 新建同级目录 `TimeXer_TaskA_v2/`，复制原始CSV快照、`prepare.py`、`train.py`、`adapters.py`、vendor源码、评估脚本及必要依赖。v1目录只读。任务A的 `protocol.json` 只改 `protocol` 名称和 `models` 列表；学习率网格 {1e-4, 3e-4, 1e-3}、默认wd=1e-4、五个种子、epochs、patience、batch、dropout、梯度裁剪全部不变。参数分组差异另存运行记录。

**基线复用。** 七个基线不在v2中重训。v2的报告脚本直接读取v1的 `result.json`、`test_metrics.json`、`test_predictions.csv`，复用前做两项检查：

- 每个 `best.pt` 的SHA256与v1 `result.json` 中记录的值一致。
- 原基线未完整保存35组验证逐样本预测。分别在独立进程中，用v1原代码和v2保留的基线代码加载同一个v1权重，在同一验证包、同一设备和eval模式下推理。反标准化后逐样本最大差小于1e-6 m，并核对验证RMSE与原记录。验证预测与比较凭据只写入v2，v1文件不改。不能仅凭“代码未改”的文字声明确认复用。

**数据包。** 在v2空的数据打包目录运行 `prepare`，不复制v1的 `packing_audit.json`，避免新协议名称触发旧协议校验。对train/val/test/scaler的数组键、dtype、形状及内容逐项用 `np.array_equal` 比对v1，包括时间轴、标签索引、持续性预测和标准化参数。npz压缩文件字节差异不作为数值差异，两个版本的文件哈希分别留档。

**新增模型代码。** 在v2新建 `02_训练流程/03_模型设计/timexer_variants.py`，包含独立组件、参数分组函数和组合类：

| 类 | 作用 | 新增参数 |
|---|---|---|
| `LastAnchorOutput` | 把TimeXer输出的参照从窗口均值换成最后实测值：`pred − 窗口均值 + x_last`，在训练标准化坐标内计算 | 0 |
| `ControlDetailTokens(mode)` | 取目标站瞬时流量和全部孔开度（任务A为3项）最近3步，减去块均值，较早9步填0。`raw` 保持训练集标准化尺度；`norm` 再除以该变量完整12步的 `sqrt(var(unbiased=False)+1e-5)`；`zero` 全部置0。细节拼入日历 `x_mark`，经原共享嵌入进入交叉注意力 | 0 |
| `external_path_groups(model, wd)` | 按参数名把 `ex_embedding` 和所有 `cross_attention` 参数分入 wd=0 组，其余参数保持 wd，返回Adam参数组 | 0 |
| `TimeXerVariant(anchor, control, path_decay)` | 继承并按原参数构造 `NativeForecast` 的TimeXer分支，仅在变体类内重写输入整理与前向调用；保留原 `network` 和全部主干参数；提供 `optimizer_groups(wd)` | 0 |

原 `NativeForecast.forward(x)` 会自行构造日历，外层简单包裹不能注入新标记。变体前向明确执行：从x分出物理量与日历；生成细节；拼接marks；调用原 `self.network(physical, marks, None, None)`；取目标输出；最后按开关应用LA。无细节时marks为[B,12,3]，有细节时为[B,12,3+K]。物理量完整保留并走原窗口归一化，日历及补充细节走原独立时间输入接口。

规范：通道按 `packing_audit.json` 字段名及任务站点键查索引；K为目标站流量加孔数，不写死为3。校验字段存在、索引唯一、目标通道正确、物理量与日历划分完整；参数分组覆盖全部可训练参数且无重复，PD组非空且参数名匹配。检查输入[B,12,C]、marks与输出[B,1]，出错给中文说明。新类写清晰中文注释，vendor源码和原基线实现不改。

**训练代码的唯一拟议改动。** 在v2的 `train.py` 中，仅为 `train_job` 与 `smoke` 两处优化器构造接入参数组。正式训练使用：

```python
# 模型可声明自己的参数分组（例如外部通路免衰减）；未声明的模型行为与v1完全相同
params = model.optimizer_groups(cfg["weight_decay"]) if hasattr(model, "optimizer_groups") else model.parameters()
optimizer = torch.optim.Adam(params, lr=job["lr"], weight_decay=cfg["weight_decay"])
```

`smoke` 没有 `job` 变量，必须保留原固定学习率：

```python
# 接口检查沿用原smoke的学习率，不能引用此函数中不存在的job变量
params = model.optimizer_groups(cfg["weight_decay"]) if hasattr(model, "optimizer_groups") else model.parameters()
optimizer = torch.optim.Adam(params, lr=0.001, weight_decay=cfg["weight_decay"])
```

优化器类型、学习率搜索规则、损失、早停等保持原设置；PD有意改变部分参数的有效衰减，不能称衰减规则完全不变。七个基线没有该分组方法，行为与v1一致。参数分组是对原“不修改Optimizer”边界的一处拟议例外，需在实施范围及论文方法中明确披露；本次文档修订不执行该改动，也不以文档自述替代后续实施指令。

`adapters.py` 的 `build()` 只增加一个显式变体注册分支：按§3名称清单映射开关，原七个名称继续走原分支；不接受未列入计划的任意组合。变体在构造时延迟导入，避免继承 `NativeForecast` 时循环导入。启用V9时同一注册表加入 `iTransformer_LA` 和 `TimeFilter_LA`；LA包装须转发底层模型每次前向产生的 `auxiliary_loss`，特别是TimeFilter的辅助损失，不能因包装而丢失。

**上线前检查（全部通过才训练）：**

- R1：批量1和8的随机输入对每个新变体前向，输出[B,1]且无NaN/Inf；批量8反向梯度有限。再用目标站4孔的完整元数据及对应C维随机张量前向，确认不依赖17通道或K=3；假数据只作接口检查。
- R2：关闭新增组件时与原TimeXer预测一致；原头部归一化增量置0时，LA预测在浮点容差内等于x_last。`zero`标记全零；`raw`最近块和为零，块内加常量不改变细节，末步变化只影响该通道最近块；`norm`与`raw`只差上述窗口尺度因子。V9另检查TimeFilter辅助损失保留。
- R3：保存参数名、各组参数量和实际wd；PD免衰减组仅含外部嵌入与交叉注意力，其他参数wd=1e-4。H1若启用，门控参数列为单独命名的wd=0组，不混称原主干外部通路；检查无遗漏、无重复。
- R4：用v2代码严格加载08轮 LastAnchor_PathDecay 的已有权重，验证集预测与原记录一致（参数名不同时只做名称映射）。
- R5：`smoke`对全部新变体通过，保存、严格重载及预测一致。用形状检查、计算图梯度及小幅输入扰动确认上游与本站接口连接；有限扰动响应不等于水文有效性，训练后弱响应也不直接判为接口失败。性能作用由正式对照检验。

## 2. 统一训练协议（P1）

所有TimeXer变体沿用基线的训练及选参流程：种子42在 {1e-4, 3e-4, 1e-3} 上各训练一次，按验证RMSE选学习率，再补齐种子123、2024、2025、3407。每个变体7次训练。共同条件为同一数据包、70/10/20划分、训练段标准化、Adam、batch64、dropout0.1、最多100轮、patience10、梯度裁剪5。搜索预算相同，不要求最后选中同一个学习率。

损失保留原实现：TimeXer及其变体使用原MSE；TimeFilter及其LA包装保留MSE加0.05倍辅助损失；其他基线不改。因此主表写“共同数据、基础流程和调参预算”，不能写“所有模型的Loss完全相同”。默认参数wd=1e-4；PD仅在指定外部参数组设wd=0，H1若启用另有K+1个门控参数免衰减，均记录并消融。不得改成AdamW或其他优化器。

06–11轮中全网wd=0得到的结果（包括当前Control3Raw）不进入本计划主表，作为开发记录保留。06轮全网wd=1e-4及08轮选择性衰减结果也不与新代码训练记录混记，只作复现与机制核对。

**PD与C3的交互对照。** V4优于V7只说明“有C3时PD有收益”，不能区分PD的一般收益与PD对C3的促进。分别计算每种子的C3收益：`gain_PD = MSE(V3) − MSE(V4)`，`gain_wd = MSE(V2) − MSE(V7)`；交互量 `I = gain_PD − gain_wd`。I为正表示PD条件下C3带来的MSE下降更大。报告两项收益、I的五种子均值、同种子方向和§7配对分块区间。

只有I均值为正、至少4/5种子为正且区间下界大于0时，才写“在当前条件下，PD增强了C3Raw表达的收益”；开发验证段结论仍属探索性。V7没有对应的无PD全零标记对照，因此该交互针对C3Raw整体表达，不单独证明幅值机制，更不证明PD是控制信息生效的必要条件。

## 4. 平稳段问题（P5）

**现状。** 已有各版本的验证集平稳段RMSE都高于持续性预测的0.743 mm：LA（wd=1e-4）0.884，LA_PD 0.994，wd=0版C3Raw 1.087 mm。总体优势来自快速变化组。

**诊断（只用训练集和验证集）：**

| 编号 | 内容 | 用途 |
|---|---|---|
| D7 | 训练段目标水位一阶差分的滞后1自相关；同时检查存储分辨率、重复值、连续记录及可取得的仪器信息 | 只提供观测噪声或差分效应线索；接近−0.5不能独立证明噪声主导，也不能确定不可约误差下限 |
| D8 | 在完整训练段和验证段，使用与H1完全相同的最近3步本站流量及开度细节幅度，按“本站开度是否变化”和“本站流量幅度是否高于训练中位数”分四格；各格再报告真实平稳/中等/快速样本数及误差 | 判断是否有历史条件可识别的无益修正，不先按未来真实平稳标签筛选诊断样本；报告V4与保持不变的同样本MSE差及分块区间 |

**D7解释边界。** 假设真实水位恒定、观测含独立噪声，则观测差分的滞后1相关可为−0.5；但历史平均仍可能比保持最后一个带噪观测更准确。因此不能用该相关值解释平稳段全部退化。分组自相关按原时间索引保留相邻关系，不能筛出零散平稳样本后拼接计算。没有重复测量或经过验证的观测模型时，不报告数值噪声下限；小数位数只描述存储值，不等同于仪器精度。

**D8条件固定。** 对 `raw` 细节定义 `a_k = max(abs(detail[:, :, k]))`，与H1输入一致。开度变化按最近3步各孔存储值是否变化判定；若有仪器分辨率，则在训练前改用对应阈值并写入 `criteria.json`，没有该信息时只称“记录值变化”。流量高低阈值为训练段 `a_flow` 的中位数，验证及测试不重估。原12步上游流量分组可保留为描述性分析，不能用来支持一个不读取上游流量的H1。

**D8启动条件。** “开度记录不变且本站流量幅度低”这一格中，验证集 `MSE(V4) − MSE(保持不变)` 为正且按§7计算的配对分块区间下界大于0，训练段方向一致；其余三格合并后V4优于保持不变，才认为存在条件收缩的探索性依据。四格均报告样本数、误差贡献及历史条件安静但未来快速变化的样本数。空格、区间不可计算或跨0均不启动H1；不因诊断结果不理想更换条件或阈值。

**H1：历史条件下的增量收缩（只在D8支持时做，作为V10）。**

- 假设：某些由本站近期流量及开度历史识别的样本，V4修正量含可收缩的误差。开度不变、流量平稳不必然意味着水位不变，流量不平衡与传播滞后仍可能引起水位变化；不将本假设写成水力定律。
- 与已否定方案的区别：08、10轮否定的是按水位历史波动做门控（波动与下一步绝对变化的Spearman相关约0.22）。H1按控制量是否变化做门控，条件变量不同。
- 结构：独立模块，输入为控制细节标记的逐项最大绝对值（K维），经 Linear(K→1) 和 sigmoid 得到标量 g，最终增量乘以 g。偏置初始化为4、权重为0，使 g≈0.98，起点接近V4。任务A新增4个参数。
- 位置：输出端，作用于增量，在加回 x_last 之前。
- 衰减：门控参数单列wd=0组，R3清单须含这K+1个参数。耦合衰减对偏置有向0收缩的倾向，但与数据梯度共同作用，不能预言偏置必然归零或g必为0.5。
- 风险：门控可能成为常数、饱和，或抑制即将发生的真实变化；它只能缩小修正量，不能修正错误的增量方向，g≈0.98也不是严格恒等初始化。报告g的分布和各组误差，按§5判断；不增加门控监督损失，不改训练策略。

D8不支持时不做H1。平稳段差距及观测精度信息不足如实写入局限，不用推测的噪声下限代替解释。

## 8. 创新性定位（P14）

**单独看都有先例：** 最后观测值参照（NLinear、Persistence Initialization），补回归一化丢失的信息（Non-stationary Transformer、SIN、SeesawNet），分参数组设置衰减是常规训练技巧。09轮文献核查已记录。

**拟检验的统一叙述：** 在近持续性的单步水位任务中，联合检查TimeXer的输出参照、近期动态表达及外部通路正则化是否适合稀疏操作变化。闸门开度是操作状态，实测过闸流量是同时受开度、水位等影响的水力响应，不能直接等同于独立人为控制指令，也不能仅因作为外部输入就宣称严格外生。

- 输出参照：检验最新实测水位参照是否优于窗口均值，不预设其对所有状态或模型都有效（C1）。
- 近期动态表达：检验本站开度与流量的近期细节是否提供额外收益；Raw对Norm的对照也通过时，才主张保留幅值有优势（C2）。
- 外部通路正则化：检验指定外部参数组免衰减能否恢复弱信息通路并改善预测（C3）。PD覆盖共享外部嵌入及全部交叉注意力，其中也含日历与其他水位变量，不是仅针对控制字段的专属参数通路。

V2/V3/V4/V7的交互对照检验PD与近期细节表达是否协同；不成立时只报告独立收益，不把V4对V7单项比较包装成必要性证据。H1若成立，只支持特定历史条件下的条件收缩，不能写成“控制静止时水位必然不变”。参数、梯度和注意力变化说明模型机制，不证明真实水文因果。

**写作约束：** 定位为渐进式应用方法研究，不宣称首次或已证明足够新颖；相关先例需在写作时复核具体来源。只有新站点测试支持时才描述同一系统内的可复现收益，不扩展成跨流域或时间外推。某项判据不成立时按§5收窄主张，不换名包装；未与独立线性模型比较的局限保留。期刊适配性待实际增益、工程意义及新站点证据齐备后判断。
